
# DevelopersHub Data Science Internship  
## Task 4: Predicting Insurance Claim Amounts  

## Objective  
To predict medical insurance charges based on personal attributes such as age, BMI, smoking status, gender, number of children, and region using Linear Regression.

## Approach  
- Loaded and explored the insurance dataset  
- Checked missing values and dataset structure  
- Converted categorical variables using one-hot encoding  
- Performed exploratory data analysis (EDA) using visualizations  
- Trained a Linear Regression model  
- Evaluated model using MAE and RMSE  

## Key Insights  
- Smoking is the most important factor affecting insurance charges  
- Age and BMI also have a strong positive impact on cost  
- The model shows moderate prediction performance  
- Errors (MAE ~4181, RMSE ~5796) indicate some variation in predictions  

## Tools Used  
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Scikit-learn  

## Conclusion  
The Linear Regression model successfully predicts insurance charges and helps identify key factors influencing medical costs. Smoking status, age, and BMI are the strongest predictors in this dataset.
