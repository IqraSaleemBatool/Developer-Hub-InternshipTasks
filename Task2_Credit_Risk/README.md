
# DevelopersHub Data Science Internship

## Task 2: Credit Risk Prediction

### Objective

To predict whether a loan applicant is likely to default or not using logistic regression.

### Approach

* Handled missing values in loan amount, gender, and credit history
* Performed EDA using histograms and scatter plots
* Trained Logistic Regression model with class balancing
* Evaluated using accuracy and confusion matrix

### Key Insights

* Initial model was biased toward predicting only approved cases
* Class balancing improved prediction of both classes
* Final accuracy: 57% with balanced predictions
* Income and loan amount are key factors

### Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn

### Conclusion

The model successfully predicts loan approval with 57% accuracy. Handling imbalanced data is important for fair and meaningful predictions.
