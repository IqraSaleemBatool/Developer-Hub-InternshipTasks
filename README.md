## Task 1: Iris Dataset Visualization

### Objective

To explore and visualize the Iris dataset using Python libraries.

* Petal length and width are strong indicators of species

### Tools Used

* Matplotlib
* Seaborn

This task helped in understanding data visualization techniques and feature relationships.
